## 标线实测流程（V4 起）

用户没法停车看参数，所以采用「正常跑 + 日志离线标定」：

1. 烧 V4，`MK_ACT_ENABLE=0`（`control.c`）：标线状态机照常运行、写日志，但**不改车速**，车正常跑完。
2. 日志每行末尾 `O=<cm>` 是**发车后前进里程**（只在 `Stop_1=1` 且编码器为正时累加，车原地爬坡不算）。
3. 车跑过菱形/人行横道时，看 `DI`、`CW` 什么时候从 0 变 1，记下当时的 `O` 和 `near` 行号——
   这就是「行号 ↔ 车头前距离」的对照表。
4. 用对照表把 `MK_CW_STOPLINE_ROW`（停车位置）定准，再把 `MK_ACT_ENABLE` 改回 1 正式执行减速/停车。

## 调参阶段约定（2026-10-22 起）

- `Lu_UI.h` 的 `PARAM_TUNING = 1`：上电**不读 flash**，一律用代码默认值（zy=63 / Differ=13 / 曝光 1010 / 增益 44 / STrim=0 / 中位 917）。避免旧参数覆盖新默认。
- 长按 S5 保存时同时写第 **11** 页和第 **10** 页（驱动只支持 0~11 页，用 17 会触发 `zf_assert`）。
- 舵机中位 `Steer_Mid` 例外：即使 `PARAM_TUNING=1`，上电也会从第 10 页恢复（现场校准结果必须能掉电保存）。
