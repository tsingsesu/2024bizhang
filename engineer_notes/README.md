## 2026-10-26 这一天的改动（按重要性）

### 1. 锥桶绕行（`code/control.c`、`code/Img_analyse.c`）

| 参数/逻辑 | 值 | 说明 |
|---|---|---|
| `CONE_LANE_CM` | 170 | 变道保持的**里程**（原来按时间 1 秒，减速时横移量减半） |
| `CONE_LANE_HALF` | 18 | 绕行目标点偏移；22=满舵987（太猛出跑道）、14=972（太小会撞） |
| `CONE_TRIG_ROW` | 36 | 锥桶要近到第 36 行才触发，避免提前 3~4 米就做完变道 |
| `CONE_MAX_GROUPS` | 2 | **赛道上只有左右各一处障碍**，第 3 次以后的触发全是误报（终点附近会自己打方向） |
| 方向 | `dir = slalom_dir` | 强制交错：第一次左、第二次右。**不再看锥桶在画面偏左还是偏右** |
| 选道 | `lane_k = dir<0 ? 0 : 100` | 绕行时连同「选哪条道」一起切，否则循迹会把车拉回原道 |

`Img_analyse.c` 里 `Cone_Scan` 的扫描窗口门槛 `c1 < c0 + 25` 改成了 **`+ 50`**：刚发车时车道读数不稳（实测 `L=29 R=71`，真实是 76），窗口被裁成 `[31,69]`，锥桶在 `x=87` 扫不到——这就是「第一次障碍识别比后面差」的原因。

### 2. 标线误判（`code/Img_analyse.c`）

自制锥桶近看是一条 20+px 连续白带，满足老的 `run_max>=22 && wc>=22`，被判成人行横道 → `mk_state=2` → **停车 5 秒**。

现在 `Marker_Scan` 改成按本行车道几何判断：白带必须**横跨 ≥60% 车道宽且盖住车道中心**才算横道（`MK_CW_SPAN_PCT`）。同时删掉了「只看到 1~3 行就升格成横道」的停车线捷径。

`MK_CW_CONFIRM` 15→60、`MK_DIA_CONFIRM` 8→32：这两个计数器按 5ms 中断累加，而 `mk_cw_seen` 每 ~20ms 才更新，原来的 15 实际只等于 4 个相机帧。

### 3. 开机右打死（`code/Lu_UI.c`、`code/Lu_UI.h`）

`PARAM_TUNING=1` 本该「不读 flash」，但 `Parameter_Read()` 里有个例外照样从 flash 恢复 `Steer_Mid`。flash 里若留着早期标定的 857，开机就被打成接近右打死。
新增开关 **`FLASH_RESTORE_STEER_MID = 0`**，现在中位始终用代码里的 917。定稿存进 flash 后再改回 1。

### 4. 终点停车（`code/control.c`）

**标线判据不可用**，这是实测结论：

```
Find_Stop 的窗口（第 30~65 行 × 第 10~60 列）正好夹在两条车道线之间，
平时本来就是黑的。
  「全黑」(aaa<2)：中途 O=580/998/1387/2416/2777/3037 都出现，最长连续 45 帧
  「全白」(A=1836)：O=4100 附近也出现
→ 两个方向都在赛道中间大量误报，判不出终点
```

所以改成**按里程停**：

```c
uint16 end_stop_cm = 0;   // ★跑到这个里程(cm)就断电机，0 = 关闭
```

**设置方法**：完整跑一圈，看日志最后一行的 `O=`（发车后前进里程），填进 `end_stop_cm`。

### 5. 试过但撤掉的（别再走一遍）

- `STEER_LANE_W_DEF` 43→75：图传量出来一条道确实是 76px，但改成 75 后 `w > lw_ema*8/5` 的阈值变成 121，**永远走「本道中心」分支，`lane_k` 选道失效**，绕行不再换道。**保持 43**。
- 不可信帧判据加 `0x0100/0x0200`（边线贴画面边缘）：这条路路面比视野宽，`L=1`/`R=117` 是**正常**的，加进去几乎每帧都被判成不可信，`pt` 一直沿用旧值，车乱窜。
- `r_ok` 上界 117→120：没改善，已撤回。
- `pt` 三帧中值滤波：第一版把**滤波后的值**存回历史，三个数里两个相等时中值恒等于该值 → **永久锁死**，`duty`/`TP` 全部冻结。后来修正为存原始值，但实测主要抖动是两帧交替，中值滤不掉，也撤了。

## 标线实测流程（V4 起）

用户没法停车看参数，所以采用「正常跑 + 日志离线标定」：

1. 烧 V4，`MK_ACT_ENABLE=0`（`control.c`）：标线状态机照常运行、写日志，但**不改车速**，车正常跑完。
2. 日志每行末尾 `O=<cm>` 是**发车后前进里程**（只在 `Stop_1=1` 且编码器为正时累加，车原地爬坡不算）。
3. 车跑过菱形/人行横道时，看 `DI`、`CW` 什么时候从 0 变 1，记下当时的 `O` 和 `near` 行号——
   这就是「行号 ↔ 车头前距离」的对照表。
4. 用对照表把 `MK_CW_STOPLINE_ROW`（停车位置）定准，再把 `MK_ACT_ENABLE` 改回 1 正式执行减速/停车。
