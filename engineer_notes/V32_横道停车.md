# V32 横道前不停车 / 横道前右偏

## 急诊卡

- 烧录后日志应显示 **V32**。
- 横道这一段重点看 4 个字段：
  - `CW=seen/near/rows`（`mk_cw_seen` / `mk_cw_near` / 满足条件的行数）
  - `CB=` 当前帧认定的人行横道白条条数（≥2 才算）
  - `MK=` 状态机（0 巡线 / 1 菱形减速 / 2 横道停车 / 3 低速通过 / 4 永久停车）
  - `NW=` 近处白条（第 45~58 行、中间窗口有 ≥22px 连续白）
- 正常应该是：接近横道时 `CB=2`、`CW=1/40以上/4以上` → `MK=2` → `WT` 涨到 5000 → `MK=3`。

## 三个改动

### 1. `MK_STOP_ROW` 45 → 40

停车条件要求 `mk_cw_near >= MK_STOP_ROW`。`mk_cw_near` 是「横道最后一条被认定的白条所在行」，
V23 在同一台车上实测最大只到 **44**，45 永远够不到 —— 横道看得见也不会停。

### 2. 计数器丢一帧不再清零

```c
if(mk_cw_seen) { if(mk_cw_run < 255) mk_cw_run ++; }
else if(mk_cw_run) mk_cw_run --;          /* 原来是 = 0 */
```

`MK_CW_CONFIRM` 是 15 **帧**、`MK_CW_NEAR_CONFIRM` 是 3 帧，原来两个都是「连续」计数。
实车上一帧漏检（反光、车身阴影、白条被前轮挡住）就整段归零，15 帧永远攒不满。
现在改成有漏检就退一格。

最终判定仍然要求当前帧 `mk_cw_seen`，所以不会因为衰减而误停。

### 3. 看到横道就走中线

```c
if(MK_ACT_ENABLE && mk_state < 2 && !cone_steering && (mk_cw_seen || mk_near_white) && pt >= 0)
    pt = Point_Mid;
```

斑马线的白条会把 `Left_Line` 往右顶（`Traversal_Mid_Line` 是从中心往两边找第一个白色跳变，
先撞到斑马线就当成左边界了），于是 `pt = Left + w/2` 往右偏十几像素 —— 这就是「横道前右转」。

`!cone_steering` 是必须的：绕锥桶时 `mk_near_white` 也会是 1，不能在这里把绕行目标点抹掉。
